# Answers

Every practice item in this book has an answer here, grouped by chapter and numbered like the practice: the answers for section 2.1 sit under "2.1 Grammar Basics", and item 7 in the practice is item 7 here.

Try each item before you look. Say the Japanese out loud, write it by hand, and only then check. Where a question has more than one good answer, the answer given is a model, not the only correct one: if yours uses a different word or a different level of politeness and still fits the situation, count it as right. The moment you can explain *why* your answer differs is the moment the grammar has clicked.
